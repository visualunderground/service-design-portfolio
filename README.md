# Service design portfolio

Static Astro website with MDX content, published automatically to GitHub Pages.

- `content/`: editable pages, projects and gallery content.
- `public/`: local images and PDF attachments.
- `src/components/`: presentation components.
- `src/pages/`: page layout and routing.
- `.github/workflows/pages.yml`: automatic deployment.

## Local development

```sh
npm install
npm run dev
npm run build
```

No Super or Notion service is needed to build the site. The résumé remains unpublished.
